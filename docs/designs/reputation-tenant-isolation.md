## Vision

NewRelay is already multi-tenant: each customer is an `Account`, APIs live under `/api/v1/accounts/:account_id`, and `EnsureCurrentAccountHelper` sets `Current.account`. Isolation is a convention (remember the WHERE), not a database lock.

This plan does **not** add schema-per-tenant, Postgres RLS, or reseller-as-operator. It closes live Reputation holes: per-customer public writes, the unauthenticated sync enqueue, and mock tokens that expire before use. The walk-in QR review page stays a public form on purpose.

```
  CURRENT                         THIS PR                         LATER
  Account + Current.account  -->  Video/feedback/r/:token         Unique index, ADR,
  QR review URL is public         cannot skip a live token        expired page, other
  Sync webhook is unauthenticated Public sync route deleted       modules (TODOS)
                                  QR stays public-by-design
```

## Architecture (this PR)

```
  Walk-in QR / Configuration copy-link
    GET/POST /reputation/review/:account_id
    -> Account.find (public form, unchanged)

  Per-customer email / WhatsApp / video
    GET /r/:token
      -> find ReviewRequest by token
      -> 404 unless sent|delivered|clicked
      -> redirect Google or video recorder

    GET/POST video recorder
      -> find ReviewRequest by token FIRST
      -> @account = request.account
      -> 404 unless live token
      -> persist on that account

    POST /reputation/feedback
      -> find by token, 2A gate
      -> txn: create submission, then completed

  Dashboard
    EnsureCurrentAccountHelper -> Current.account.reputation_*.find(id)

  Sync
    DELETED  /api/v1/reputation/sync/:id
    KEEP     POST /api/v1/accounts/:id/reputation/integrations/:id/sync
    KEEP     ReviewSyncJob from connect + cron
             perform(integration_id)  # arity unchanged
```

### Data flow (video / feedback)

```
  token --> find ReviewRequest --> persist --> 200
    missing/scheduled     404
    completed             404 this PR (replay TODO with unique index)
    mock send             status stays sent; log still prints /r/:token
```

### Deploy / rollback

```
  no job arity change -> in-flight Sidekiq OK
  public sync route gone -> bookmarked URL 404s (no in-tree caller)
  QR URLs unchanged
  rollback = git revert
```
